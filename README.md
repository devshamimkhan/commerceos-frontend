# SportsShop Admin Frontend

Next.js App Router + TypeScript + Tailwind CSS.

## Setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and set `API_BASE_URL` to the shared commerce backend API.
3. Run locally with `npm run dev`.

Use `npm run build` followed by `npm start` in production. Product image selection and uploads require both the shared backend and media server to be configured and reachable.
